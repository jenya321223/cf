CYBER ZONE — инструкция

1. Распакуйте архив.
2. Откройте index.html в браузере.
3. Для бронирования и заказа еды сначала зарегистрируйте аккаунт.
4. Данные аккаунта, бронирований и заказов сохраняются в localStorage браузера.
5. Интернет для работы сайта не нужен.

Файлы:
index.html — главная
prices.html — цены
pc.html — ПК
games.html — игры
food.html — еда
about.html — о нас
contacts.html — контакты
login.html — вход и регистрация
booking.html — бронирование
style.css — дизайн
script.js — общая логика
